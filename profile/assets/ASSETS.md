# Profile artwork

Based on the FPS Labs brand guide v0.2.0: https://fps-labs-brand-guide.vercel.app/

The hero uses the supplied FPS mark without alteration, Geist Mono 600 outlined as SVG paths, the stage and paper palettes, Lab Blue, and a static scrubber motif. Outlined text avoids font loading failures in GitHub image rendering. Full accessible text is included in image descriptions and the README.

Wide and compact artwork is selected through HTML picture sources. The compact layout applies at viewport widths up to 600px. Theme selection follows prefers-color-scheme; GitHub controls the surrounding page's typography and theme. No scripts, animations, remote fonts, custom CSS, or external image generators are required.

Font source: Geist Mono by Vercel, SIL Open Font License 1.1. See OFL.txt.
